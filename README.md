**SHE SHIELD – Women Safety Web Application**
**Overview**
SHE SHIELD is a women safety web application that enables users to send instant SOS alerts with live location to trusted contacts during emergencies.

**Problem**
Women often face unsafe situations where panic and delayed communication prevent quick help.

**Solution**
The app provides a one-tap SOS button that shares the user’s real-time location using Google Maps and sends alerts via Firebase.

**Features**
One-tap SOS alert
Live location sharing
Emergency contact management
Responsive web UI

**Google Technologies Used**
Google Maps API
Google Firebase (Authentication, Realtime Database, Hosting)

**Tech Stack**
HTML, CSS, JavaScript, Firebase

**Future Scope**
Voice-triggered SOS, AI alerts using Google ML Kit, emergency service integration.
